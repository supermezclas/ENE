# Objetivo principal

Construir una plataforma profesional para:

- Analizar sitios web de noticias.
- Detectar automáticamente artículos periodísticos.
- Extraer información fiel.
- Clasificarla.
- Conservar el artículo original.
- Generar contenido editorial mediante IA.
- Exportar a múltiples formatos.

---

# Principios del proyecto

1. Nunca inventar información.
2. Siempre conservar el artículo original.
3. Toda síntesis debe derivarse únicamente del texto original.
4. Mantener transparencia editorial.
5. Toda noticia será almacenada como un Expediente Editorial.
